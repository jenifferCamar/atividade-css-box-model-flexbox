# Atividade CSS — Box Model e Flexbox

Projeto desenvolvido para a **Atividade 01 da Aula 07 — Frameworks CSS**.

Demonstra o Box Model CSS e 20 propriedades ou configurações de Flexbox organizando 20 elementos de forma responsiva.

## Deploy

**[Acessar projeto](https://atividade-css-box-model-flexbox.vercel.app)**

## Tecnologias

- HTML5
- CSS3 (arquivo externo)

## Estrutura

```text
atividade-css-box-model-flexbox/
├── index.html      # Estrutura e 20 elementos demonstrando Box Model
├── style.css       # Estilos com 20 propriedades de Flexbox
├── vercel.json     # Configuração do deploy estático
├── package.json    # Metadados do projeto
└── .gitignore      # Arquivos ignorados pelo Git
```
